# FlightSim Update Manager

**Windows-Tool zur Übersicht und Verwaltung von Software rund um Microsoft Flight Simulator.**

FlightSim Update Manager unterstützt dabei, installierte Programme und begleitende Tools zu erfassen, ihre Update-Möglichkeiten zu prüfen und verfügbare Aktualisierungen übersichtlich zu verwalten.

> **Entwicklungsstatus:** In Entwicklung. Es steht derzeit **kein öffentlicher Download** und **kein Kaufangebot** bereit. Funktionsumfang und Verfügbarkeit können sich bis zur Veröffentlichung ändern.

## Geplanter Funktionsumfang

- **Software erkennen:** Installierte Programme und ausgewählte MSFS-bezogene Tools finden.
- **Persönliche Übersicht:** Programme dem Flugsimulator zuordnen und Auswahl speichern.
- **Update-Möglichkeiten prüfen:** Je nach Programm beispielsweise über GitHub Releases, winget oder Herstellerquellen.
- **Updates verwalten:** Unterstützte Updates direkt durchführen; bei anderen Programmen zum zuständigen Launcher oder Download führen.
- **Status und Verlauf:** Prüfstatus, Updateergebnisse und Hinweise bei Problemen anzeigen.

Nicht jede Software unterstützt eine automatische Versionsprüfung oder Installation. Die Unterstützung ist vom jeweiligen Hersteller und Updateweg abhängig.
